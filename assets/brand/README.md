Leonardo Andujar designated the supplied `triadlang.png` as TRIAD’s official symbol on 2026-09-18. [triad-symbol.png](triad-symbol.png) is a byte-identical copy. Use this master for the logo; the covers are compositions for presentation, not replacement master marks.

The covers were made with the built-in ImageGen tool, using the supplied symbol as the visual reference. They are brand artwork. Figures and animations shown as results come directly from their simulation records and are not generated by ImageGen.

## Cover direction and prompts

English: create a premium landscape 2:1 GitHub README brand cover. Nearly black background; faithful ivory/cyan orbital symbol and central star on the right; monumental ivory TRIAD wordmark on the left. Exact copy: NONSTANDARD QUANTUM PHYSICS / TRIAD / UNIVERSE LAB / A universe in motion. / OSCILLATION / SELF-REFERENCE / COUPLING. Preserve the luminous refinement, use clean readable typography and controlled margins; no invented scientific diagrams or metrics.

Português: preserve the English cover’s composition, symbol, lighting and typography. Replace only the copy with FÍSICA QUÂNTICA NÃO PADRÃO / TRIAD / UNIVERSO LAB / Um universo em movimento. / OSCILAÇÃO / AUTORREFERÊNCIA / ACOPLAMENTO, adjusting the subtitle size to retain clear space.

The symbol master is used unchanged in the website. Its display framing is CSS; no pixels are rewritten. Build exports use exact file copies. New identity assets belong here, with provenance; numerical figures stay with their studies.
