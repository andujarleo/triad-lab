# Next steps

The foundation provides a catalog, documentation in two languages, experiment
templates and a run record. The lab can grow in the directions below; these are
directions, not completed results or dated commitments.

New work follows the [project rules](project-rules.md): the complete immutable equation, dynamic self-organization and no external calibration toward a chosen result.

- **New series:** add questions and implementations of the complete TRIAD dynamics to the catalog.
- **More runs:** record additional environments and outputs with their own provenance.
- **More languages:** translate navigation and explanations around the same IDs and artifacts.
- **Interactive exploration:** add viewers that read the preserved data.
- **Maintenance:** use the included integrity, local-link and translation checks as the catalog grows.

## Building on the T archive

- Assess archived implementations and available dependencies before preparing runnable bundles. Preserve a historical reproduction as such; identify whether a setup follows the complete-equation rules before proposing it as a new TRIAD execution.
- Recover missing runtimes, inputs and references listed in provenance.
- Record new runs separately and compare parameters and results with the preserved source.
