# Words you will encounter

| Term | In this lab |
|---|---|
| **Field / Campo** | A value assigned to each location; here it is represented numerically on a grid or through modes. |
| **Density / Densidade** | In many field studies, \|Ψ\|². A plotted magnitude, whose physical interpretation depends on the model. |
| **Phase / Fase** | The angle of a complex number or an oscillator’s position within its cycle. |
| **Memory / Memória** | A model variable or interaction that carries a trace of earlier states. It is not necessarily biological or conscious memory. |
| **Grid / Grade** | The sampled locations where a field is represented. A 64³ grid contains 64×64×64 positions. |
| **Time step / Passo de tempo** | The interval used for one numerical update. Changing it can change numerical error and results. |
| **Seed / Semente** | An input to a random-number generator. Exact replay also depends on code, parameters, backend and environment. |
| **Checkpoint** | A saved internal state used to inspect or continue a run. The fields actually stored vary between files. |
| **Spectrum / Espectro** | A description of how a signal or field is distributed across frequencies or spatial scales. |
| **Diagnostic / Diagnóstico** | A measurement calculated to test a specific property. It can fail even when a simulation produces an image. |
| **Convergence / Convergência** | Checking whether a numerical result becomes stable as resolution or step size is refined. |
| **Control / Controle** | A comparison designed to separate the proposed effect from other explanations. |
| **R5 / Θ_core** | Names used for reference configurations in the historical notes; consult the actual parameters and solver version. |
| **QM / Q00–Q04** | Historical identifiers for a field-diagnostics sequence. Part of the engineering and chronology of TRIAD, whose proposal concerns nonstandard quantum physics. |
| **Recorded / Registrado** | Some material from a run was supplied. This is an availability label, not a validation grade. |
| **Inconclusive / Inconclusivo** | The recorded test did not establish the proposed conclusion under its stated criteria. |
| **Hash / SHA-256** | A fingerprint of file bytes. Matching hashes support file identity, not scientific equivalence between experiments. |
