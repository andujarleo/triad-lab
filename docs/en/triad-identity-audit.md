# TRIAD identity audit

**What is complete TRIAD, study by study.**

English is the principal language of this audit. The other versions are maintained translations of the same verdicts.

This register examines each of the 65 catalogued studies point by point and states explicitly whether its preserved record is an execution of the complete TRIAD equation: P1 oscillation, P2 self-reference (present self-interaction and memory) and P3 coupling (dissipation and bath) acting together.

Each row carries one of four identity verdicts, the maintained scope line, and evidence links to the execution-audit record and the reviewed source or file index. No simulation was rerun and no preserved file was altered for this audit.

## How each study was examined

The examination follows the preserved chain from source to verdict:

```text
preserved source → implemented operators → declared run conditions → saved measurements → identity verdict
```

Names such as full or pure do not establish completeness; only the reviewed update, configuration and run binding do. A term-off or modified system is identified as not complete TRIAD, with its conditions recorded.

## Point-by-point checks

Every study was read against the same eight checks:

- **P1 · Oscillation retained.** The update keeps the oscillatory part of the dynamics.
- **P2 · Present self-interaction retained.** The update keeps the instantaneous nonlinear self-interaction.
- **P2 · Memory retained, three scales.** Three evolving memory fields carry density history and feed back on the state.
- **P3 · Bath retained, FDT lock.** Dissipation and the stochastic bath act jointly with the FDT-locked amplitude.
- **No term disabled.** No memory, bath, fractional or interaction term is removed, zeroed or frozen during evolution.
- **No undisclosed trajectory rescaling.** No per-step renormalization or state guard rewrites the evolved field; declared inputs stay visible.
- **Source and run bound.** Supplied source, configuration, seeds, grid and horizon identify the executed run; no unbound external runtime.
- **Observable defined.** Detectors, thresholds and labels are defined; a new label is not a new trajectory.
