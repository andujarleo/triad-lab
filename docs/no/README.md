# TRIAD Lab på norsk

Dette språket publiserer identitetsrevisjonen punkt for punkt: hvilke poster som er fullstendig TRIAD og hvilke som ikke er det, med konklusjon og bevis per studie.

[Les TRIAD-identitetsrevisjonen](triad-identity-audit.md)

Studiesider og veiledninger forblir på engelsk (hovedspråk) og portugisisk; lenker faller tilbake på engelsk der oversettelse mangler.
