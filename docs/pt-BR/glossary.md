# Palavras que você vai encontrar

| Termo | Neste lab |
|---|---|
| **Field / Campo** | Um valor associado a cada posição; aqui ele é representado em uma grade ou por modos. |
| **Density / Densidade** | Em muitos estudos de campo, \|Ψ\|². Uma grandeza desenhada, cuja interpretação física depende do modelo. |
| **Phase / Fase** | O ângulo de um número complexo ou a posição de um oscilador dentro de seu ciclo. |
| **Memory / Memória** | Uma variável ou interação do modelo que guarda uma marca de estados anteriores. Não é necessariamente memória biológica ou consciente. |
| **Grid / Grade** | As posições amostradas onde o campo é representado. Uma grade 64³ contém 64×64×64 posições. |
| **Time step / Passo de tempo** | O intervalo usado em uma atualização numérica. Mudá-lo pode alterar o erro numérico e os resultados. |
| **Seed / Semente** | Uma entrada do gerador de números aleatórios. A repetição exata também depende de código, parâmetros, backend e ambiente. |
| **Checkpoint** | Um estado interno salvo para inspecionar ou continuar uma execução. Os campos armazenados variam entre arquivos. |
| **Spectrum / Espectro** | Uma descrição de como um sinal ou campo se distribui entre frequências ou escalas espaciais. |
| **Diagnostic / Diagnóstico** | Uma medida calculada para testar uma propriedade específica. Ela pode falhar mesmo quando a simulação produz uma imagem. |
| **Convergence / Convergência** | Verificar se um resultado numérico se estabiliza ao refinar a resolução ou o passo. |
| **Control / Controle** | Uma comparação planejada para distinguir o efeito proposto de outras explicações. |
| **R5 / Θ_core** | Nomes de configurações de referência nas notas históricas; consulte os parâmetros e a versão do solver. |
| **QM / Q00–Q04** | Identificadores históricos de uma sequência de diagnósticos do campo. Parte da engenharia e da cronologia da TRIAD, cuja proposta é física quântica não padrão. |
| **Recorded / Registrado** | Algum material de uma execução foi fornecido. É uma indicação de disponibilidade, não um grau de validação. |
| **Inconclusive / Inconclusivo** | O teste registrado não estabeleceu a conclusão proposta segundo seus critérios. |
| **Hash / SHA-256** | Uma impressão digital dos bytes do arquivo. Hashes iguais indicam identidade do arquivo, não equivalência científica entre experimentos. |
