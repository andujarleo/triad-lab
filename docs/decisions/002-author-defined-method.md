Date: 2026-09-18. Basis: Leonardo Andujar’s explicit instructions during the repository audit.

The author defines its method: self-calibration from chaos to dynamic equilibrium, dynamic crystallization, no external calibration to force a result, no isolation of terms and no Popperian falsification protocol.

The [project rules](../en/project-rules.md) ([português](../pt-BR/project-rules.md)) are the public reference for this method. [AGENTS.md](../../AGENTS.md) carries the same instructions into future repository work. This supersedes the identity framing, provisional P1 wording and ambiguous equation-edition language in [the original observatory decision](001-public-observatory.md).

## Application

P1 means oscillation, P2 self-reference (instantaneous interaction and temporal memory), and P3 coupling. Document revisions and implementation histories do not change the equation. The author’s ontological interpretation is attributed to him; numerical statements link to the actual record and keep their conditions.

Technical review checks file integrity, implementation fidelity and traceability. It does not impose a different research method. Source files and numerical verdicts remain preserved even where their wording or implementation differs from the author’s rules. The maintained page explains that difference with a source link. Membership and interpretation remain with the author.
