三个不同层面：几何对声音所为、所测得的，以及这对意图证明不了的。无文本，无"普世神圣频率"之神话。

1. 前文字遗址对声音真正能做的

石腔即共鸣器。模态频率约声速 / 2L（若有喉加体积，则为亥姆霍兹变体）。约 20 °C 空气中，110 Hz 波长约 3.1 米。凡容得下成年人的腔室，都倾向于在该频段有某模态。这是物理，非设计之证据。

有用的检验不是"在 110 Hz 附近共鸣吗？"。而是：频谱窄且在不相连腔室重复吗？几何需多面墙同时精调吗？人声（非扬声器）耦合并把模态传遍整个建筑群吗？

2. 四处遗址

Hal Saflieni（马耳他，约公元前 3600–2500 年）——最强的一例

唯一完整到足以做现代测量的遗址。三层凿于抱球虫灰岩。

测量：

- 神谕室：报告在约 70 Hz 与 114 Hz 的双共鸣；男低音耦合并激发整个地下宫殿。皮鼓经谐波激发；贝/号几乎不能。
- Till（2017，《Antiquity》）：63 Hz 混响长达 16 秒；测得主共鸣约 41、72、76 Hz——证实低频效应，未复现此前全部数值。
- Wolfe、Swanson 与 Till（2020，JAs Reports）：中层峰谱要求独立腔室不相连之墙的联合调谐。峰近乎等距，接近全音音阶（比率约 9:8 与 10:9）。这是几何非偶然的最有力的统计论证。

Xaghra（戈佐，圈加地下宫殿）：25–34 Hz 宽峰（次声加可听阈），不同于 Saflieni。不是同一乐器。

Saflieni 无著名的太阳对准。是纯腔。

Newgrange（爱尔兰，约公元前 3200 年）——唯一在同一体量合太阳与腔室者

太阳事实：顶窗让冬至日出进入甬道，照亮墓室深处数分钟。此已确立。

声学事实：Jahn、Devereux 与 Ibison（1996，JASA）测得共鸣约 110 Hz（六个英/爱腔室 95–120 Hz 频段，包括 Newgrange）。方法：耳加声压计，无自动频谱，预选样本。30 年未以现代规程复现。

后期的物理限制：Newgrange 维持驻波；不生强亥姆霍兹——圆石与石冢空腔吸收。按尺寸的瑞利预测约 109.7 Hz，合乎尺寸的预期，非调律之证明。

Maeshowe（奥克尼）是更好的一对：冬至（日落）加极严密的干砌石加更清晰的亥姆霍兹。Newgrange 是最著名的一对，非声学上最"干净"的。

Stonehenge（约公元前 3000–2200 年）——对准有，腔室无

对准：夏至日出于 Heel Stone 之上；冬季轴线相反。属实。

声学：完整纪念物的 1:12 模型（157 石，约公元前 2200 年），索尔福德大学（Cox、Fazenda、Greaney 2020）：

- 中频平均混响时间：0.64 ± 0.03 秒
- 圈内言语放大：4.3 ± 0.9 分贝
- 无可闻回声；内石散射而不成闭腔
- 声不向外投射
- 作者结论：声是石头布局动因的可能性不大。

蓝砂岩击之有声（石发声）。这是材质，非腔室。

Saflieni 之外的马耳他地下宫殿

Xaghra 与 Santa Lucija 小地下宫殿形同而谱不同。Tarxien（地上）有低频，但是神庙，非等值腔室。"马耳他体系"是负建筑加地面神庙；唯 Saflieni 有经得起细查的测量集。

3. 旧石器骨笛——测得的音程，非"音阶"

Hohle Fels（奥瑞纳，距今 ≥35,000 校准年前）

兀鹫桡骨，存 21.8 厘米，5 孔加 V 刻。孔边细线示钻前有标记。制作事实：确凿。

复制品（同骨、不同技法）不给出唯一的音集。一项把 HF1 当单簧管吹奏（管一端封闭）的研究报道：

| 赫兹 | 近似音 | 音程 |
| --- | --- | --- |
| 456 | 降 B4 | 半音 |
| 499 | B4 | 半音 |
| 530 | C5 | 半音 |
| 630 | 降 E5 | 全音 |
| 707 | F5 | 半音 |
| 834 | 降 A5 | 全音 |
| 936 | 降 B5 | — |

相对平均律偏差 −38 至 +23 音分。非现代自然音阶。

作边棱笛时（同文另一复原）：G5-A5-B5-D6-F#6-G6。

五声是方便的描述，非唯一测量。吹气压力改变音高数十赫兹。

坚实的是：有意制作、定标开孔、非平均半音阶、约一八度加超吹的音域。

Divje Babe I（约 5–6 万年前，莫斯特文化背景）

洞熊幼崽股骨，2 完整孔加痕迹。状态仍有争议：人工钻孔还是食肉齿。支持方（Turk、Dimkaroski）的论据是位置加可吹复制品。反对方是埋藏学及遗址数百股骨中的唯一性。

复制品：

- Dimkaroski：3/2 八度，非律制，可做现代吐音——取决于复原长度、吹口与第 4 孔（拇指）。
- Atema："压扁"四音列，四度极低（约 411 音分），非干净自然音阶。
- Fink（1997）：自然音阶残段——要求原长大于幼崽骨所允许。

无"原本的真实音程"。有复原品的音程。把 Divje Babe 当测过的笛子，是跳过本体论步骤。

4. 同一遗址的太阳对准加共鸣腔

真实交集，不强求：

| 遗址 | 太阳 | 腔室/共鸣 | 成对强度 |
| --- | --- | --- | --- |
| Newgrange | 冬至（日出） | 墓室加甬道；约 110 Hz（1996，弱） | 唯一著名者 |
| Maeshowe | 冬至（日落） | 物理上比 Newgrange 更干净的亥姆霍兹 | 最佳一对 |
| Loughcrew | 分点 | 1996 年研究 95–120 Hz 频段 | 弱 |
| Stonehenge | 至点 | 开圈，混响 0.64 秒，无腔 | 无 |
| Hal Saflieni | 唯声学 | 测得最好的新石器共鸣器 | — |

Newgrange 是同一空间既受日光束、又被测为共鸣器的唯一体量。巧合在遗址，不在证实的"回路"：无人于光束进入时测墓室模态。顶窗开启时 Newgrange 的亥姆霍兹降至约 2 Hz（次声，非歌）。不同机制。

5. 推不出的

- 110 Hz 作巨石常数。几乎凡人造腔室在该频段皆有模态。Cook 等（2008）见 110 Hz 脑电变化（语言相对失活、半球转移）——小样本、实验室纯音，非遗址之歌。不证实"神经设计"。
- Saflieni 的自觉乐阶。2020 年论文示频谱似全音。似 ≠ 乐谱。
- 笛子 = 腔室的同一语法。Hohle Fels 与 Newgrange 相隔三万年、一千五百公里。文化连续是假设，非数据。
- 意图。营造者经验主义（听、再挖）是起码机制[在转换后的来源中无法辨认之断句]。
