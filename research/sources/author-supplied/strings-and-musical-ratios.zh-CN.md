此表所含，约简至文本中可证者——无铁匠传说，无"毕达哥拉斯听见宇宙"，无赫兹。

操作性事实

这些作者皆不测频率。他们测弦长之比（或后期话语中"运动"之比）。张力与密度恒定时，现代频率即长度比之倒数。这是物理；不在他们的词汇中。

传统混淆的两个不同对象：

1. 乐器调律（四音列、里拉八度）。
2. 用相同比率的宇宙论建构。

柏拉图做（2）。菲洛劳斯与阿尔希塔斯近于（1），并跃向宇宙。尼科马库斯与杨布里科斯已是接受史。

菲洛劳斯（残篇 6a）——最小核心

经尼科马库斯与斯托拜乌传下的文本。实践词汇（hypate、mese、trite、neate），非实验室。

| 音程 | 残篇中名 | 比率 |
| --- | --- | --- |
| syllaba | 四度 | 4:3 |
| di' oxeian | 五度 | 3:2 |
| dia pasan / harmonia | 八度 | 2:1 |
| epogdoos | 全音 | 9:8 = (3:2)/(4:3) |
| diesis | 四度余二全音之残 | 256:243 |

残篇中明确的算术推论：

- 八度 = 5 × (9:8) + 2 diesis
- 五度 = 3 × (9:8) + 1 diesis
- 四度 = 2 × (9:8) + 1 diesis

此已包含永不消失的问题：(9:8)^6 > 2:1。六个毕达哥拉斯全音超出八度。差即科玛。菲洛劳斯不"解"之；他描述实践已用的自然音阶，并命名余项。菲洛劳斯的宇宙和谐（有限加无限之合）是对该结构的类比。非自天经验推导。

阿尔希塔斯——首个尝试三种属的首个体系

三个中项（残篇 2）：

- 算术：a − b = b − c。例：12、9、6 → 12:9 = 4:3（四度），9:6 = 3:2（五度）
- 几何：a/b = b/c
- 和声（subcontraria）：大端超中项之部分，即中项超小端之部分。例：12、8、6 → 12:8 = 3:2，8:6 = 4:3

决定性定理：超特别比 (n+1):n 的项之间无有理几何中项。

故八度、五度、四度、全音不能以整数等比平分。此杀死了"真半音"即 √9:8 之说。

四音列划分（托勒密《和声学》I.13），皆闭合 4:3；最低音程在三属中相同（28:27）：

| 属 | 比率（高 → 低） |
| --- | --- |
| 自然属 | 9:8 · 8:7 · 28:27 |
| 半音属 | 32:27 · 243:224 · 28:27 |
| 四分音属 | 5:4 · 36:35 · 28:27 |

与菲洛劳斯/柏拉图之别：阿尔希塔斯的自然属不是 9:8 · 9:8 : 256:243。他偏重超特别比与中项，而非叠五度/四度调律。

另有声学残篇：音高系于运动之速/力。物理假设，非测量。

柏拉图《蒂迈欧》35a–36d——世界灵魂，非里拉手册

造物主的程序：

1. 混存在、同、异。
2. 切份：1、2、3、4、8、9、27（2 与 3 之幂——lambda）。
3. 插入算术与和声中项 → 3:2、4:3、9:8 出现。
4. 以 9:8 全音填各 4:3；余为 256:243。
5. 将带中分，交叉成 X，弯为二圆（同/异）；内部分为七行星圆，循倍与三倍音程。

所得音阶即菲洛劳斯的毕达哥拉斯自然音阶，延展数个八度。非行星"奏"此比率之证据。它是柏拉图认同为宇宙思想秩序、后又认同为轨道的数字生成器。

文本不做的：校准耳朵、描述四分音/半音属、断言赫兹。

《蒂迈欧》53c–55c——另一层

此处对象是世界之体，非灵魂。

- 火：四面体
- 气：八面体
- 水：二十面体
- 土：立方体
- 全体：十二面体

体之间的联系是几何比例与三角形面，非 1-2-3-4-8-9-27 数列。把 35a–36d 与 53c–55c 当作同一"音乐密码"，是把两个建构压扁。柏拉图并置二者；不等同二者。

欧几里得《弦之分》——公理加独弦

结构：物理序言加《几何原本》式命题加弦的实用划分。

序言（所设）：

- 无击无动则寂；
- 音高与撞击密度相关；
- 声之间关系即整数之比；
- 协和须为倍比（n:1）或超特别比（(n+1):n）。

该著欲证之果：

- 八度 = 2:1
- 五度 = 3:2
- 四度 = 4:3
- 全音 = 9:8
- 全音不分为二等比（同一阿尔希塔斯定理）

内在局限，标准自身已见：八度加四度 = 8:3，耳以为协和，而非倍比亦非超特别比。托勒密将恰以此攻毕达哥拉斯教条。《弦之分》选定标准，又弃伤标准之数据。

末诸命题描述弦的直线划分。此即传统的实验仪器——非铁锤传说。

托勒密《和声学》——唯一拒两种教条者

方法立场：

- 毕达哥拉斯派：比率正确，耳被当作噪声；
- 阿里斯托塞努斯派：耳主权，比率被当作对象之外物。

托勒密两要：以独弦验比率；以耳决何者实为旋律。喜超特别比，但现象（8:3）证伪时，不受"唯倍比或 epimoric 即协和"之规则。

卷三又转向灵魂、德性、黄道。此处文本不再是乐器和声，复归宇宙类比。把卷 I–II 与卷 III 分开是稳妥的读法；混为一谈则不是。

[句首在转换中丢失]现代纯律的大 5:4。此系有用接受，非"失落的希腊秘密"。

尼科马库斯《手册》加杨布里科斯《毕达哥拉斯传》

传述层，公元 2–4 世纪。

可用处：

- 引菲洛劳斯 6a；
- 系统化中项与七弦至八弦音阶；
- 冻结铁匠与重锤叙事。

作公元前 6–5 世纪史料之不可用处：

- 铁锤故事物理上为假（锤重不如果传说要求决定音高；要紧的是棒/砧或弦）；
- 杨布里科斯是新柏拉图圣徒传。宜于绘制神话如何拼装，不宜于阿尔希塔斯测得何物。

以尼科马库斯为菲洛劳斯之证：可。以之为历史毕达哥拉斯之证：不可。

阿里斯托塞努斯——阻浪漫化的一刀

科学对象：音高空间中嗓音的连续统，按旋律功能组织。仪器：训练过的耳（akoe）加理智（dianoia）。

与《弦之分》不相容之论：

- 四度含二全音半；
- 全音在知觉中分为等半音；
- 音程是连续统的量，首要地不是比率。

尖锐的数值冲突：

纯四度为 4:3、全音为 9:8，则四度不含 2.5 个等全音。阿里斯托塞努斯知其所谈是另一标准：乐耳接受为"同一步"者，非整数比闭合者。

无阿里斯托塞努斯，表成数字神学。有之，则粗事实留存：同一文化生出两个不可约标准——有理闭合对耳之判断。托勒密是唯一试图焊接二者、而不伪称一者取消另一者的人。

此希腊层授权何事——不授权何事

授权：

- 弦实践中稳定的一小组比率：2:1、3:2、4:3、9:8 及 256:243 之余；
- 一否定定理：超特别音程不能有理平分；
- 两个冲突的本体论（比率对耳），皆希腊，皆古代；
- 柏拉图以此比率为世界灵魂与轨道之骨架——《蒂迈欧》明言，非推断。

不授权：

- 赫兹频率、"528"、"432"或任何绝对定标；
- 柏拉图体与灵魂音阶之同一；
- 铁匠铺的毕达哥拉斯作实验；
- 天奏里拉音阶。

若 corpus 循同一逻辑续行，下一个有用切口已非希腊：是罗马/波爱修斯冻结者，及中世纪修道院承为 musica mundana 者[末句在转换后的来源中无法辨认]。
