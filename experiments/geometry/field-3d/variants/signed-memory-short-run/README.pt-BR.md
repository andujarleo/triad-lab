# Memória com sinal e execução padrão mais curta

Esta implementação arquivada distinta usa coeficientes de memória tanh com sinal, outra expressão de amortecimento e 400 passos por padrão. Também contém menos gráficos de diagnóstico que a base. Essas diferenças foram preservadas, sem uniformizá-las. Compare equações e configurações antes das saídas.
