# Cordas, átomos e escala

**Como padrões localizados respondem a mudanças de tamanho e amplitude?**

Duas sondagens investigam relações entre átomos e cordas e escolhas de tamanho da caixa e amplitude. Os nomes descrevem construções do modelo; não estabelecem que sejam átomos físicos.
