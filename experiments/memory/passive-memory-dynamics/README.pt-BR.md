# Dinâmica passiva da memória

**A memória mantém um padrão fixo ou continua redistribuindo-o?**

O relatório descreve deslocamentos recorrentes de escala, em vez de um cristal permanentemente fixo. A norma registrada permanece próxima de um. Uma trajetória gêmea curta não constitui um resultado de Lyapunov de longo prazo.
